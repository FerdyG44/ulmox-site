ULMOX

リアルな瞬間を、リアルな人と。

瞬間を共有しよう。 世界を見つけよう。

リアルな瞬間をひとつ共有すると、まったく別の場所で暮らす人たちのリアルな瞬間が届きます。

ULMOXの使い方

3つのシンプルなステップ。作り込む必要も、演じる必要もありません。

  1. 瞬間を共有する

    その日のリアルな出来事を撮って、世界へ送り出します。

  2. 瞬間を受け取る

    誰かの瞬間が届きます。通りの風景、窓からの眺め、なんでもない午後。

  3. さらに見てまわる

    World LiveとGlobalを開いて、いま世界がどこにあるのかを確かめましょう。

World Live

世界のさまざまな場所から共有されたリアルな瞬間を、ひとつのインタラクティブな世界の上でめぐれます。

地球を回し、気になった場所で止めて、そこから届いた瞬間を見てみましょう。

Connections

リアルな瞬間は、リアルなつながりになれる。

スワイプなし。フォロワー競争なし。まず瞬間で出会います。

  1. リアルな瞬間を共有する

    始まりはプロフィールではなく、実際に過ごした出来事です。

  2. 自然に人と出会う

    やり取りした瞬間を通じて、ほかの人と出会います。

  3. Connectionが可能になる

    本物の出会いは、ふたりの間でConnectionを可能にすることがあります。

  4. リクエストを送る

    可能になったら、どちらからでもConnectionを申し込めます。

  5. ふたりとも承認する

    おたがいがそれぞれ承認するまで、何も開きません。

  6. 会話を始める

    有効なConnectionでは、テキストメッセージのやり取りと相手のプロフィール閲覧ができます。

最後まで主導権はあなたにあります。報告、ブロック、Connectionの終了はいつでも使えます。

Connections と任意のメッセージ翻訳は段階的に導入されており、すべてのアカウントやインストール済みのすべてのアプリバージョンでまだ利用できるとは限りません。

Global

人々がULMOXコミュニティ全体に向けて共有することを選んだ、リアルな瞬間を見つけられます。

コミュニティがいま何をオープンに共有しているかが、ひと目でわかる場所です。

ULMOXが違う理由

  • 整えたプロフィールではなく、リアルな瞬間

    共有するのは、なりたい自分の姿ではなく、実際に過ごした瞬間です。

  • 身のまわりの外にいる人たち

    ULMOXは、知り合い経由では出会えなかった人たちを連れてきます。

  • フォロワー競争がない

    追いかける数字も、築くべき観客もありません。

  • つながりは出会いから育つ

    会話が始まるのは、先にリアルな出来事があったからです。

  • そこに生きる人を通して見る世界

    どの瞬間も、実際にその場にいる誰かから届きます。

安全とコントロール

メッセージが見知らぬ相手に開かれることはありません。会話が始まるのは、ULMOXが求める出会いとふたりの承認がそろってからで、いつでも終了できます。

  • 報告する

    ユーザーまたは個別のメッセージを報告できます。確認するのは人です。

  • ブロックする

    ブロックすると、双方向のやり取りが止まります。

  • Connectionを終了する

    離れることはいつでもでき、そのペアについては元に戻りません。
